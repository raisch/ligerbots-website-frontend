Class: module:vehicle

module:vehicle()

Vehicle service for managing reusable vehicles (ride collection).

Conceptually, a "vehicle" is defined in the ride collection and can be reused across multiple trips. When creating a new trip ride (trip_ride), values from a vehicle record are copied into the trip_ride's ride object, so vehicles live outside the event/trip/ride/rider hierarchy.

This class uses:

  • GraphQL operations from graphql/ride.js to manage ride items.
  • Joi schema from models/ride.model.js to validate vehicle records.
